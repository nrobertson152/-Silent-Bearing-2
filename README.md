# Silent Bearing 2

The Cold War has gone hot, and the enemy has pushed you back to your home waters. Command US or
Soviet warships in a naval war set in 1988, working your way up from frigate to submarine, destroyer,
cruiser and modernised battleship.

Built with [Godot 4.7](https://godotengine.org). Every model, texture and sound is generated in code.

*Work in progress: see the open pull requests for the current state.*
